# Judging · 30 points

Six criteria, 5 points each. Scale: 1 = weak · 3 = good · 5 = excellent.

Working Product — Does the core feature work?
Usefulness — Does it solve a real problem?
Theme Alignment — Does it address the theme revealed at opening?
Creativity — Is the idea original or clever?
Ease of Use — Is it simple and intuitive?
Demo — Can you clearly show the working product?
